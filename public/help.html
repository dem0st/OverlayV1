Что куда вставлять

Быстрая памятка по настройке оверлея

1. Оверлей в OBS

В OBS добавь источник «Браузер» и вставь туда адрес оверлея:

http://localhost:3000/overlay для OBS

2. Токен панели

Вставлять никуда не надо — он уже в панели. Показать/скрыть и скопировать можно кнопкой рядом с адресом панели в верхней шапке. Лежит также в файле .token рядом с приложением.

3. Пароль OBS WebSocket

В OBS: Сервис → Настройки WebSocket — включи сервер WebSocket и задай пароль. Этот пароль потом вставь в панели в карточку OBS.

4. Ключ StreamElements (озвучка алертов)

Включи «Озвучку» в панели, затем в карточке Ключи TTS вставь API-токен StreamElements:

streamer.streamelements.com / Авторизация Страница токенов ➔

Аккаунт должен быть привязан к твоему Twitch. Токен для TTS — это JWT (overlay-токен) из раздела API-токенов в канале.

5. Ключ ElevenLabs

Если голос StreamElements не нравится — вставь API-ключ ElevenLabs в ту же карточку Ключи TTS и выбери провайдера на главном экране панели:

elevenlabs.io / Профиль / API Keys Страница ключей ➔

6. Старая панель / config.json

Если у тебя остался config.json от прошлой версии — импортируй его прямо из панели:

Настройки (config.json) → Импортировать config.json — канал, OBS, чат и сцена перенесутся.

Подсказка: сцена загружается с http://localhost:3000/overlay. После смены пароля OBS переподключение происходит автоматически; панель перезагружается по Ctrl+R или из меню «Открыть → Перезагрузить панель».
